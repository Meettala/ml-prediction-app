# Commercialisation and Private Production Boundary

This public MIT-licensed repository is a portfolio and reference implementation. It demonstrates engineering decisions but is not a governed valuation product.

A paid or client-facing service should be developed in a separate private proprietary repository with at least:

- current, licensed and documented data sources;
- data contracts, quality checks and retention rules;
- authentication, authorisation, tenant isolation and rate limiting;
- managed secrets and encrypted transport/storage;
- signed model artifacts or a governed model registry;
- deployment approvals and rollback procedures;
- prediction, latency, error and drift monitoring;
- model performance by geography and relevant subgroups;
- legal, fairness, consumer-protection and financial-services review where applicable;
- incident response, audit logs and independent security/model-risk testing.

The public project must not contain private datasets, customer records, production credentials, proprietary prompts, commercial infrastructure details or confidential model artifacts.

Do not market the public demonstration as a current property valuation, appraisal, lending decision tool, investment recommendation or guarantee of accuracy.
