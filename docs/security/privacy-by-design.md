# Privacy by design — ML Prediction App

- Dataset: scikit-learn's built-in California Housing dataset, derived
  from 1990 US Census block-group aggregates. No individual-level or
  personally identifiable data is used.
- No user data is collected or stored by the API or Streamlit app — a
  prediction request is stateless and not logged beyond standard server
  logs.
- No authentication or personal accounts needed for this tool.
